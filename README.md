# 國小四年級國語科互動式學習網頁教學指引手冊（第八課《四季的頭髮》）

歡迎使用專為臺灣國小四年級設計的**「國小國語科互動式學習網頁」——第八課《四季的頭髮》**！
本系統依據國小四年級國語第八課童詩**《四季的頭髮》**（作者：林世仁）教材標準設計，依循 108 課綱核心素養標準，為現場教師與學童自主學習量身打造。

## 📂 一、專案檔案結構與存放位置

本專案位於獨立的第八課資料夾中：

```
reading-app/
│
├── index.html              <-- 主網頁程式檔（雙擊即可直接在瀏覽器開啟）
├── style.css               <-- 介面樣式表（大字體、高對比、護眼溫馨配色、童詩分行排版）
├── lesson-data.js          <-- 【第八課獨立教材與題庫資料檔】（完全解耦設計）
├── app.js                  <-- 互動學習引擎（音效合成、語音朗讀、點選配對、句子重組、闖關計分、錯題重練）
├── .nojekyll               <-- 確保 GitHub Pages 靜態檔案正常載入
├── css/style.css           <-- 樣式備用同步檔
├── js/app.js               <-- 互動引擎備用同步檔
├── js/lesson-data.js       <-- 教材題庫備用同步檔
└── README.md               <-- 本教學指引與 GitHub Pages 發布手冊
```

> **📌 GitHub Pages 與本機雙向相容保證**：
> 所有網頁核心檔案（`index.html`、`style.css`、`lesson-data.js`、`app.js`）皆已統一配置於相對路徑，無論是在 Windows 本機雙擊開啟，或是發布至 GitHub Pages 的子路徑（如 `https://<帳號>.github.io/<專案名>/`），都能 100% 正常載入樣式、音效與互動腳本！

## 🚀 二、如何直接開啟與課堂使用

### 1. 教師投影使用（桌機 / 筆電）
1. 在資料夾中**對著 `index.html` 連點滑鼠左鍵兩下（Double Click）**。
2. 系統會自動以預設瀏覽器（Google Chrome 或 Microsoft Edge）開啟。
3. **教室投影大字模式**：
   - 點擊右上角 **「🔍 教室投影大字」** 按鈕，文字會自動放大至適合教室後排學生觀看的 23px 超大字體。
   - 按下鍵盤 `F11` 進入全螢幕，立即化身專屬電子白板互動教學軟體！

### 2. 教室平板或學生觸控操作
- 系統全域支援**觸控點選**（Touch-friendly），所有按鈕、生字卡、詞語配對皆具備大觸控區，學生用手指輕點即可作答。
- 內建 **Web Audio 離線音效合成** 與 **瀏覽器繁體中文語音朗讀（Web Speech API）**，點擊朗讀或生字卡即可聽取標準發音。

## 🌐 四、如何將這個專案發布到新的 GitHub 專案（GitHub Pages）

請依照以下簡單步驟，將這個第八課網站發布到您獨立的 GitHub 專案：

### 步驟 1：在 GitHub 建立新 Repository（倉庫）
1. 登入您的 [GitHub 帳號](https://github.com/)。
2. 點擊右上角的 **「+」** ➔ 選擇 **「New repository」**。
3. 設定倉庫名稱（Repository name），例如：`mandarin-lesson8` 或 `chinese-reading-app-8`。
4. 選擇 **Public**（公開）。
5. **不要勾選**「Add a README file」（因為本專案已經有完整的 README.md）。
6. 點擊 **「Create repository」**。

### 步驟 2：將本專案推送到新的 GitHub 專案
在您的本機電腦上，開啟命令提示字元（PowerShell 或 Git Bash），切換到本專案資料夾：

```powershell
cd "c:\Users\user\Desktop\國語互動網頁 -8\reading-app"
```

依序執行以下 Git 指令（將 `<您的GitHub帳號>` 與 `<專案名稱>` 替換為您的實際名稱）：

```powershell
# 1. 初始化 git 倉庫（若已有 .git 可直接繼續）
git init

# 2. 將所有檔案加入暫存區
git add .

# 3. 提交變更
git commit -m "feat: 完成第八課《四季的頭髮》國語互動教學網頁"

# 4. 將分支命名為 main
git branch -M main

# 5. 關聯到您新建立的 GitHub 倉庫
git remote add origin https://github.com/<您的GitHub帳號>/<專案名稱>.git

# 6. 推送到 GitHub
git push -u origin main
```

*(如果之前這個資料夾已經關聯了第一課的 remote，請先執行 `git remote remove origin` 再執行第 5 步。)*

### 步驟 3：在 GitHub 開啟 GitHub Pages 網頁託管
1. 進入您剛建立的 GitHub 倉庫頁面。
2. 點擊上方的 **「Settings」**（設定）標籤。
3. 在左側選單中找到並點擊 **「Pages」**。
4. 在 **「Build and deployment」** 區塊：
   - **Source** 選擇：`Deploy from a branch`。
   - **Branch** 選擇：`main` 分支，資料夾選擇 `/ (root)`。
5. 點擊 **「Save」**（儲存）。
6. 等待 1~2 分鐘，頁面頂端會顯示綠色勾勾與網址：
   **`https://<您的GitHub帳號>.github.io/<專案名稱>/`**
7. 點擊該網址，即可在任何手機、平板、電腦上開啟第八課互動網頁！
